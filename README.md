# Smtppois

VB6 SMTP ActiveX control (`smtppois.ocx` / `smtp`, FairChild): Winsock-based SMTP user control for embedding send-mail in other apps. Open `smtppois.vbp` in the VB6 IDE and compile/register the OCX.
